# Magento customer base

Magento's active merchant base is roughly **100,000–130,000 stores worldwide**.

- BuiltWith currently detects about **128,600 live Magento websites**, including approximately **83,300 running Magento 2**. Some represent multiple storefronts owned by one company, so this is not 128,600 unique businesses. [BuiltWith Magento statistics](https://trends.builtwith.com/shop/Magento)
- A separate Store Leads estimate puts the base near **111,500 active stores in Q1 2026**.
- The paid **Adobe Commerce/Enterprise** segment is much smaller: BuiltWith detects roughly **6,000–7,000 live enterprise installations**. Adobe does not publicly disclose a clean paying-customer count.

For market sizing, a reasonable working estimate is:

- **~110,000 active Magento storefronts**
- **~70,000–100,000 merchant organizations**, after accounting for multi-store setups
- **~6,000–7,000 enterprise Adobe Commerce sites**

Magento therefore has a meaningful but contracting installed base. It is not Shopify-sized, but it remains commercially attractive because Magento merchants skew toward larger, technically complex stores with higher spending on extensions, agencies, hosting, maintenance, and integrations.
